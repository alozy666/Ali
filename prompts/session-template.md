# 🧾 قوالب عرض الجلسة — للحَكَم الآلي

## 1) شاشة الترحيب

```
✨ أهلاً بكم في «وَكُن مِنَ العارِفِينَ» ✨

تخيّلوا طريقاً من نور يمتدّ من الكعبة المشرفة في مكة،
يشقّ الليل حتى يبلغ القباب الذهبية في سامراء المقدسة…
على جانبيه كتابٌ مضمّخ بالأنوار، وإسطرلابٌ ذهبي يدور.
هذا طريقكم الليلة. سبع محطات، وأربع ألعاب، ومعرفة موثّقة بمصادرها.

📝 أولاً: أسماء الفرق المشاركة؟ (فريقان على الأقل)

ثم اختاروا:
 [1] رحلة السفر الكاملة — 7 محطات من مكة إلى سامراء
 [2] لعبة محدّدة — مَن يزيّد؟ / لَمِّح إليّ / اسأل وجاوب
 [3] النمط الشامل — جولات متنوعة بين الألعاب الأربع
```

## 2) عرض سؤال (رحلة السفر / اسأل وجاوب)

```
📍 المحطة 3 من 7 — النجف الأشرف
🎯 الدور: فريق الغدير   |   الصعوبة: متوسط (20 نقطة)
⏱️ 60 ثانية — ابدأ الآن

السؤال: أين ضُرب أمير المؤمنين (ع) الضربة التي استُشهد بها؟

 أ) في داره
 ب) في محراب مسجد الكوفة
 ج) في مسجد النبي (ص)
 د) في ساحة المعركة

🃏 كروتك المتاحة: [خليها لغيري] · [تغيير السؤال] · [خيارات للسؤال]
```

## 3) كشف الإجابة

```
✅ الإجابة الصحيحة: (ب) في محراب مسجد الكوفة
💡 ضربه ابن ملجم وهو ساجد في صلاة الفجر، واستُشهد في الحادي والعشرين من رمضان سنة 40 هـ.
📚 المصدر: الإرشاد — الشيخ المفيد (ج1)
➕ فريق الغدير: +20 نقطة
```

## 4) جولة «مَن يزيّد؟»

```
🎲 مَن يزيّد؟
التصنيف: ألقاب السيدة فاطمة الزهراء (ع)
القاعدة: زايدوا على عدد الألقاب التي تستطيعون سردها.
صاحب أعلى مزايدة يسردها كاملةً في 30 ثانية — وإن فشل فالنقاط للمنافس.

💬 فريق الغدير، كم تذكرون؟
```

## 5) جولة «لَمِّح إليّ»

```
💡 لَمِّح إليّ — 45 ثانية
الكلمات الثلاث:
   1️⃣ زبور      2️⃣ أدعية      3️⃣ زين العابدين

الأسرع في الاستنتاج الصحيح يحصد 20 نقطة.
(تلميح رابع متاح بخصم 5 نقاط — اطلبوه إن أردتم)
```

## 6) لوحة النقاط — بعد كل جولة

```
🏆 لوحة النقاط
┌───────────────┬────────┬──────────────────────────────┐
│ الفريق        │ النقاط │ الكروت المتبقية              │
├───────────────┼────────┼──────────────────────────────┤
│ فريق الغدير   │   90   │ تغيير السؤال · خيارات للسؤال │
│ فريق الكوثر   │   70   │ خليها لغيري · تغيير السؤال   │
└───────────────┴────────┴──────────────────────────────┘
📍 المحطة الحالية: النجف الأشرف (3 من 7)
```

## 7) الشاشة الختامية

```
🏁 انتهت الرحلة — من مكة إلى سامراء

🥇 الفائز: فريق الغدير — 280 نقطة
🥈 فريق الكوثر — 210 نقطة

📊 الإحصاء:
   فريق الغدير : 14 صحيحة · 7 خاطئة · كرت لم يُستخدم: [خيارات للسؤال]
   فريق الكوثر : 14 صحيحة · 7 خاطئة · كرتان لم يُستخدما

🕌 نسأل الله أن يجعلنا وإياكم من العارفين بحق أهل البيت (ع).
```
